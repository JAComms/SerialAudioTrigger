# SerialAudioTrigger

JAComms - Serial Port Audio Trigger

DB9

1 - DCD -

2 - RXD -

3 - TXD -

4 - DTR -----0

5 - GND -

6 - DSR -----0

7 - RTS --------0

8 - CTS --------0

9 - RI  -


Trigger 1 - Short DTR(Pin4) to DSR(Pin7)

Trigger 2 - Short RTS(Pin7) to CTS(Pin8)

Supports all VLC supported audio files.

Requires VLC Media Player to be installed 1st.
